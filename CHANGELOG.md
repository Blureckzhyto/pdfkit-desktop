# Cambios · Changelog

## 1.4.0

**Español**
- **PDFKit ahora se llama Pliegue.** Mismo programa, nombre y logo nuevos. Se instala como actualización de PDFKit: tu configuración y tus datos se mudan solos, y en «Agregar o quitar programas» queda una sola entrada, «Pliegue».
- Si tenías PDFKit anclado a la barra de tareas, quita ese ancla y vuelve a anclar Pliegue (Windows no deja que el instalador lo cambie).
- Nuevo repositorio y página: github.com/Blureckzhyto/pliegue · blureckzhyto.github.io/pliegue.

**English**
- **PDFKit is now Pliegue.** Same app, new name and logo. It installs as an upgrade over PDFKit: your settings and data move automatically, and "Add or remove programs" keeps a single entry, "Pliegue".
- If PDFKit was pinned to the taskbar, unpin it and pin Pliegue again (Windows does not let the installer change pins).
- New repository and website: github.com/Blureckzhyto/pliegue · blureckzhyto.github.io/pliegue.

## 1.3.7

**Español**
- La app abre en ~1,5 s (antes 10–15 s): se instala como carpeta, con pantalla de carga inmediata y herramientas que se cargan al usarlas.
- Editor: el doble clic abre siempre el cuadro de edición; escribir o usar Retroceso sobre un texto elegido lo edita (nunca lo borra); Supr muestra un aviso con «Deshacer».
- «PDF a Excel» volvió a funcionar en la app instalada.
- Instalador más chico (210 MB).
- Código abierto (AGPL-3.0): ventana «Acerca de» con la licencia, el enlace al código fuente y las licencias de terceros (carpeta «Licencias»).

**English**
- The app opens in ~1.5 s (was 10–15 s): installed as a folder, instant splash screen, tools load on first use.
- Editor: double click always opens the inline editor; typing or Backspace on a selected text edits it (never deletes it); Delete shows an "Undo" notice.
- "PDF to Excel" works again in the installed app.
- Smaller installer (210 MB).
- Open source (AGPL-3.0): "About" window with the license, a link to the source code and third-party licenses ("Licencias" folder).
