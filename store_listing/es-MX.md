Cada bloque se copia tal cual en Partner Center → Descripciones de Store → Español (México).

## Nombre del producto

```
Pliegue
```

## Descripción breve (≤ 100 caracteres)

```
Une, divide, comprime, convierte, edita y firma PDF sin internet. Gratis, privado y sin anuncios.
```

## Descripción

```
Pliegue reúne todas tus herramientas PDF en una sola app para Windows que trabaja sin internet. Tus documentos se procesan en tu computadora: nunca se suben a ningún servidor.

ORDENAR PDF
• Unir varios PDF en uno
• Dividir por rangos, cada N páginas o por tamaño máximo (MB)
• Extraer, eliminar y reordenar páginas con miniaturas

OPTIMIZAR PDF
• Comprimir PDF para enviarlos por correo
• Reparar PDF dañados
• OCR: convierte PDF escaneados en PDF con texto que se puede buscar y copiar (español e inglés)

CONVERTIR A PDF
• JPG y otras imágenes a PDF
• Word, PowerPoint y Excel a PDF
• HTML a PDF, desde un archivo o desde una dirección web

CONVERTIR DESDE PDF
• PDF a JPG, Word, PowerPoint y Excel (extrae tablas)
• PDF a PDF/A para archivo a largo plazo

EDITAR PDF
• Editor de texto real: doble clic en un texto para cambiarlo con su misma fuente, tamaño y color
• Agregar texto, imágenes, formas y dibujos; mover y redimensionar elementos
• Rotar, recortar, números de página, marca de agua y formularios

EDITAR Y FIRMAR
• Firmar PDF con tu firma dibujada, escrita o como imagen
• Proteger con contraseña y quitar la protección
• Censurar información de forma permanente
• Comparar dos PDF y ver las diferencias

IMÁGENES
• Convertir entre PNG, JPG, WEBP, BMP, TIFF y HEIC
• Comprimir imágenes

PRIVADO DE VERDAD
Pliegue no tiene cuentas, anuncios, telemetría ni rastreadores. Funciona sin conexión; solo usa internet si escribes una dirección web en «HTML a PDF». Incluye tema claro y oscuro.

SOFTWARE LIBRE
Pliegue es gratis y de código abierto (licencia AGPL-3.0). Código fuente: https://github.com/Blureckzhyto/pliegue
```
