## Description

```
Pliegue brings all your PDF tools together in one Windows app that works offline. Your documents are processed on your computer and are never uploaded to any server.

The interface is in Spanish.

ORGANIZE PDF
• Merge several PDFs into one
• Split by ranges, every N pages or by maximum size (MB)
• Extract, delete and reorder pages with thumbnails

OPTIMIZE PDF
• Compress PDFs to send them by email
• Repair damaged PDFs
• OCR: turn scanned PDFs into searchable, copyable text (Spanish and English)

CONVERT TO PDF
• JPG and other images to PDF
• Word, PowerPoint and Excel to PDF
• HTML to PDF, from a file or a web address

CONVERT FROM PDF
• PDF to JPG, Word, PowerPoint and Excel (table extraction)
• PDF to PDF/A for long-term archiving

EDIT PDF
• Real text editor: double-click a text to change it with its own font, size and color
• Add text, images, shapes and drawings; move and resize elements
• Rotate, crop, page numbers, watermark and forms

EDIT & SIGN
• Sign PDFs with a drawn, typed or image signature
• Protect with a password and remove protection
• Permanently redact information
• Compare two PDFs and see the differences

IMAGES
• Convert between PNG, JPG, WEBP, BMP, TIFF and HEIC
• Compress images

TRULY PRIVATE
Pliegue has no accounts, ads, telemetry or trackers. It works offline and only uses the internet if you enter a web address in "HTML to PDF". Light and dark themes included.

FREE SOFTWARE
Pliegue is free and open source (AGPL-3.0 license). Source code: https://github.com/Blureckzhyto/pliegue
```
